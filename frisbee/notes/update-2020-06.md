# Noeud fit51

* ce noeud n'est pas un des 37 noeuds qu'on voit sur l'UI de r2lab.inria.fr
* et surtout nous n'avons pas actuellement de moyen de rebrûler une image sur ce noeud
* ce noeud est raccordé à un USRP X310 et un USRP N320 par des fibres.

## gestion de l'alimentation

| action | commande |
|--------|----------|
| allumer | `on-51` |
| éteindre | `off-51` |
| reset | `reset-51` |
| status | `status-51` |

## se logger

depuis faraday

```console
ssh fit51
```

## config logicielle

* fedora-32
* podman 1.9.3
* podman-docker est installé (on peut faire `docker run` à la place de `podman run` si on est paresseux)

# Gestion des USRP X310 et N320
* l' alimentation des 2 USRP est contrôlée par un Black Box Power Switch accessible à partir de faraday:


```console
firefox http://192.168.1.50 
(avec pour login admin et comme password adminet++)
```
* merci de ne pas oublier d'éteindre les USRP après utilisation ainsi que le noeud fit51

## raccordement du X310

* 2 interfaces 10Gbps SFP+ sur fit51 :
	* x310-sfp0 (en 10.51.100.1)
	* x310-sfp1 (en 10.51.101.1)

## raccordement du N320

* 2 interfaces 10Gbps SFP+ sur fit51 :
	* n320-sfp0 (en 10.51.200.1)
	* n320-sfp1 (en 10.51.201.1)

* 1 interface 1Gbps Ethernet appelée **sdr51**, joignable à partir de faraday :
	```
sliceX@faraday$ ssh root@sdr51
```

le prompt est root@ni-n3xx-31B3A77
